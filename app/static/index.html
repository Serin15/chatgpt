TRANSPARENȚĂ ÎNAINTE DE SCOR

Surse & metodologie

Știm ce măsurăm și păstrăm separat ce nu putem confirma.

Starea surselor

HTTP OK arată o cerere reușită, nu adevărul tuturor afirmațiilor unei surse.

Reguli de portofoliu

DEX: model de pool aproximativ. Crypto generale: order book observat dacă este disponibil; altfel preț de referință și slippage presupus. Fee-ul nu provine din contul unui exchange.

Ce înseamnă „solid”?

Produs, emitent, tokenomics, vesting, audit, contract și surse verificabile. Capitalizarea sau asocierea cu Trump, Musk ori Zelenski nu înlocuiesc aceste dovezi.

Evaluarea completă a fundamentelor și verificarea susținerilor oficiale nu sunt automatizate încă.

Înainte de ce listare?

Un token poate fi deja pe un DEX înainte de un CEX. Arătăm piața raportată, adresa și timestamp-ul. Pentru un presale fără piață sau preț verificabil, nu inventăm un fill.

Nu afișăm predicții „100x” sau probabilități nevalidate. AI-ul nu este conectat la execuție.
