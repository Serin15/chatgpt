# PULSE v0.2 — crypto research și experiment manual

Cererea extinsă: știri și proiecte crypto generale, persoane publice, dovezi despre proiect, piețe
unde există tranzacționare și decizii manuale cu $50 virtuali. Interfața a fost refăcută integral.

## Surse verificate pe 13 octombrie 2026

- [CoinGecko markets](https://docs.coingecko.com/demo/reference/coins-markets): până la 25 de
  active per actualizare, preț, volume și capitalizare; HTTP 200 fără cheie în probe. Observațiile
  mai vechi rămân păstrate. Catalogul nu este lista proiectelor lansate astăzi, iar prețurile
  agregate nu sunt quotes executabile.
- [CoinGecko tickers](https://docs.coingecko.com/reference/coins-id-tickers): perechi și linkuri
  de tranzacționare; probă BTC cu 8 piețe valide. Ticker-ele stale/anomalous sunt excluse. Datele
  și etichetele de trust ale furnizorului nu garantează că un exchange/pair este potrivit.
- CoinGecko project metadata: probă BTC cu 3 linkuri de site/whitepaper/repository. Genesis este
  data raportată de furnizor; linkurile și contractele nu sunt validări independente.
- [Coinbase public book](https://docs.cdp.coinbase.com/exchange/reference/exchangerestapi_getproductbook):
  `GET /products/BTC-USD/book?level=1` HTTP 200, bid/ask/cantități și timestamp. Folosim date publice,
  fără ordine sau autentificare la un cont. Comisionul de 0,6% este o presupunere configurabilă;
  comisionul real al utilizatorului nu a fost verificat. Depth este limitat la L1.
- [CoinDesk RSS](https://www.coindesk.com/arc/outboundfeeds/rss),
  [Kraken Blog RSS](https://blog.kraken.com/feed) și
  [Ethereum Foundation RSS](https://blog.ethereum.org/en/feed.xml): HTTP 200 și XML interpretat.
  La proba inițială Kraken avea un articol recent eligibil, Ethereum niciunul în fereastra de 48h.
  Zero articole recente este un rezultat valid, fără date inventate.
- Google News RSS: căutări crypto, lansări/funding, Trump, Musk, Zelenski și Claude. Titluri și
  surse de publicație, nu verificare completă a articolelor. Filtrul pentru persoane publice cere
  context crypto; nu tratăm orice știre politică drept oportunitate de token.

[Coins recently added](https://docs.coingecko.com/reference/coins-list-new) este, conform paginii
oficiale consultate, disponibil pentru **Analyst și planuri superioare**. Nu am introdus un plan
plătit și nu imităm acea acoperire prin topul pieței. Prețurile planurilor și SLA nu au fost promise.
Clientul nostru limitează cererile de piață la aproximativ 28/min și folosește cache pentru metadata
și venues. Disponibilitatea/limitele accesului public pot varia.

Domenii adăugate în draft: `api.coingecko.com`, `docs.coingecko.com`, `api.exchange.coinbase.com`,
`docs.cdp.coinbase.com`, `www.coindesk.com`, `blog.ethereum.org`, `blog.kraken.com`.
Preseturile și domeniile existente au fost păstrate. Nicio cheie/valoare secretă nu a fost salvată.

## Ce este implementat

Overview, feed filtrabil, surse primare, știri noi/citite, piață crypto generală, scanner Solana,
dosar de cercetare, linkuri de proiect și piețe raportate, portofoliu virtual, ipoteză de intrare și
jurnal. Sidebar desktop, navigare mobilă, iconuri SVG, layout responsive și grafice numai din
observații reale. Prețurile din grafice sunt observații CoinGecko; nu amestecăm midpoint-ul unui
alt exchange în graficul acelei surse.

Pentru BTC și alte active mapate, simularea poate folosi bid/ask și dimensiunea disponibilă la L1.
Ordinele peste cantitatea observată sunt respinse. Dacă lipsește book-ul la ieșirea unei poziții
intrate pe book, nu credităm o vânzare fictivă prin modelul de referință. Fee-urile și latența dintre
observație și eventuală execuție reală rămân incerte. Fără book, un experiment nou poate folosi
un model de referință cu slippage declarat. Modelele sunt în jurnal, cu `execution_verified=false`.

Soldurile/ordinele anterioare sunt păstrate. În instanța cloud, înainte de upgrade existau $100
în contul Scanner și $500 în contul de știri/Research, cu 0 ordine; s-a făcut backup SQLite consistent
în afara repository-ului. Nu am plasat ordine în locul utilizatorului.

## Criterii de precizie și următorii pași

Precizia se măsoară separat de profit: identitate și contract corecte, citare verificabilă,
prospețime, rată de potriviri false și diferența dintre prețul de semnal și intrarea observabilă.
Pasul următor este un set de cazuri verificate manual pentru anunțuri originale și proiecte;
întâi verificăm produs/echipă/tokenomics/vesting/audit, apoi putem clasifica un proiect ca solid.
Numele unei persoane, o publicație a emitentului sau capitalizarea nu sunt suficiente.

Pentru performanță păstrăm și cazurile negative: costuri, ordine respinse, poziții neieșite și date
incomplete. Comparăm ulterior strategia cu baselines pe observații viitoare, cu eșantion și perioadă
raportate. Testele software nu demonstrează un avantaj financiar.

Software-ul actualizează datele când rulează; nu cercetează și nu instalează automat versiuni noi
ale codului. Dezvoltarea continuă se face prin schimbări verificabile, teste, changelog și upgrade
controlat. Hosting cu autentificare/HTTPS și joburi persistente este o etapă ulterioară; nu este
publicat un server de trading în această versiune.
